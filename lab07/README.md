# Лабораторная работа 7. Функции и автоматические проверки

Вариант 12: чётное и больше порога.

## Запуск

```
python main.py
python test_functions.py
```

## Проверки main.py

| Ввод (число / числа / текст / порог) | Ожидаемый результат | Фактический результат |
|--------------------------------------|---------------------|-----------------------|
| `-507` / `-2 0 5 3` / `  ПРИВЕТ   Мир  ` / `2` | сумма цифр 12, среднее 1.50, `привет мир`, `[]` | сумма цифр 12, среднее 1.50, `привет мир`, `[]` |
| `0` / пустая строка / пробелы / `2` | сумма цифр 0, Нет данных, пустой текст, `[]` | сумма цифр 0, Нет данных, пустой текст, `[]` |
| `123` / `1 2 3 4 5 6` / `Текст` / `2` | сумма цифр 6, среднее 3.50, `текст`, `[4, 6]` | сумма цифр 6, среднее 3.50, `текст`, `[4, 6]` |

## Проверки варианта 12 (select_numbers)

| Вход | Ожидаемый результат |
|------|---------------------|
| `[-5, 0, 2, 5]`, порог 2 | `[]` |
| `[]`, порог 2 | `[]` |
| `[1, 2, 3, 4, 5, 6]`, порог 2 | `[4, 6]` |
| `[3, 4, 5]`, порог 3 | `[4]` |
| `[4]`, порог 4 (граница) | `[]` |
| `[4]`, порог 3 (рядом с границей) | `[4]` |
| `[-2, 0, 2, 4]`, порог 0 | `[2, 4]` |
| `[4, 4, 6, 4]`, порог 2 (повторы) | `[4, 4, 6, 4]` |

Исходный список после вызова не меняется: это проверено в `test_functions.py`.

## Проверка тестов на ошибке

В `functions.py` условие `number > threshold` было намеренно заменено на `number >= threshold`. Запуск `python test_functions.py` завершился `AssertionError` на проверке `select_numbers([-5, 0, 2, 5], 2) == []`. После возврата исправной версии выводится `Базовые проверки пройдены`.
