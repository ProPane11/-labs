# Лабораторная работа 5. Обработка строк

Вариант 12: слово содержит подстроку `ра`.

## Запуск

```
python normalize.py
python palindrome.py
python replace.py
python variant.py
```

## Проверки

### 1. Нормализация (normalize.py)

| Ввод | Ожидаемый результат | Фактический результат |
|------|---------------------|-----------------------|
| `Один два` | `Один два`, слов 2, длина 8 | `Один два`, слов 2, длина 8 |
| `  Один    два  ` | `Один два`, слов 2, длина 15 → 8 | `Один два`, слов 2, длина 15 → 8 |
| пустая строка | длина 0, слов 0 | длина 0, слов 0 |

### 2. Палиндром (palindrome.py)

| Ввод | Ожидаемый результат | Фактический результат |
|------|---------------------|-----------------------|
| `А роза упала на лапу Азора` | Палиндром | Палиндром |
| `а` | Палиндром | Палиндром |
| строка из пробелов | Нет текста | Нет текста |
| `Python` | Не палиндром | Не палиндром |
| `А!` | Не палиндром | Не палиндром |

### 3. Замена (replace.py)

| Ввод | Ожидаемый результат | Фактический результат |
|------|---------------------|-----------------------|
| `a::b:` | `a--b-`, замен 3 | `a--b-`, замен 3 |
| `abc` | `abc`, замен 0 | `abc`, замен 0 |

### Вариант 12 (variant.py)

| Ввод | Ожидаемый результат | Фактический результат |
|------|---------------------|-----------------------|
| `Анна, армия! Я читаю. Книга, край, рама.` | край, рама; количество 2 | край, рама; количество 2 |
| `Рама, РАМА. ра! дом` | рама, рама, ра; количество 3 | рама, рама, ра; количество 3 |
| пустая строка | Нет совпадений, количество 0 | Нет совпадений, количество 0 |
| `!!!` | Нет совпадений, количество 0 | Нет совпадений, количество 0 |
