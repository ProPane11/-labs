3. Предсказание результата арифметических выражений
Перед запуском программы результаты были рассчитаны вручную.
| Выражение | Ожидаемый результат | Фактический результат |
|---|---:|---:|
| `2 + 3 * 4` | `14` | `14` |
| `(2 + 3) * 4` | `20` | `20` |
| `17 // 5` | `3` | `3` |
| `17 % 5` | `2` | `2` |
| `-7 // 2` | `-4` | `-4` |
Объяснение
В выражении 2 + 3 * 4 сначала выполняется умножение, так как оно имеет более высокий приоритет:
3 * 4 = 12
2 + 12 = 14
В выражении (2 + 3) * 4 сначала вычисляется выражение в скобках:
2 + 3 = 5
5 * 4 = 20
Оператор // выполняет целочисленное деление с округлением вниз. Например:
17 // 5 = 3
Оператор % возвращает остаток от деления:
17 % 5 = 2
Для отрицательных чисел округление при // выполняется именно вниз, поэтому:
-7 // 2 = -4.

Отличие / от //
Оператор / выполняет обычное деление и возвращает результат типа float.
Например:
7 / 2 = 3.5
Оператор // выполняет целочисленное деление с округлением вниз:
7 // 2 = 3
При отрицательных числах округление также происходит вниз:
-7 // 2 = -4.
Что такое остаток от деления
Остаток показывает, сколько единиц осталось после выделения полного количества групп.
Например:
17 // 5 = 3
Это означает, что из 17 можно получить 3 полные группы по 5.
А:
17 % 5 = 2
означает, что после формирования трёх групп останется 2 единицы.
Почему форматирование :.2f не устраняет неточность float
Числа типа float хранятся в памяти в двоичной системе, поэтому некоторые десятичные дроби нельзя представить абсолютно точно.
