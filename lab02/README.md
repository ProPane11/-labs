## 3. Предсказание результата арифметических выражений

Перед запуском программы результаты были вычислены вручную.

| Выражение | Ожидаемый результат | Фактический результат |
|---|---:|---:|
| `2 + 3 * 4` | `14` | `14` |
| `(2 + 3) * 4` | `20` | `20` |
| `17 // 5` | `3` | `3` |
| `17 % 5` | `2` | `2` |
| `-7 // 2` | `-4` | `-4` |

В выражении `2 + 3 * 4` сначала выполняется умножение, поскольку оно имеет более высокий приоритет:

`2 + 12 = 14`

В выражении `(2 + 3) * 4` сначала выполняется действие в скобках:

`2 + 3 = 5`

`5 * 4 = 20`

Оператор `/` выполняет обычное деление и может возвращать дробное число. Например:

`7 / 2 = 3.5`

Оператор `//` выполняет целочисленное деление с округлением вниз:

`7 // 2 = 3`

Оператор `%` возвращает остаток от деления:

`17 % 5 = 2`

Для отрицательных чисел оператор `//` также округляет результат вниз:

`-7 // 2 = -4`.

## 6. Теоретические вопросы

### Отличие `/` от `//`

Оператор `/` используется для обычного деления. Результатом может быть дробное число.

Например:

`7 / 2 = 3.5`

Оператор `//` выполняет целочисленное деление с округлением вниз.

Например:

`7 // 2 = 3`

Для отрицательных чисел округление происходит в сторону меньшего числа:

`-7 // 2 = -4`.

### Смысл остатка от деления

Оператор `%` показывает, сколько единиц остаётся после выделения полного количества групп.

Например:

`17 // 5 = 3`

Это означает, что из 17 единиц можно составить 3 полные группы по 5.

Остаток:

`17 % 5 = 2`

То есть после формирования трёх полных групп останется 2 единицы.

### Почему форматирование не устраняет неточность `float`

Тип `float` хранит дробные числа в двоичном формате. Некоторые десятичные дроби невозможно представить в памяти абсолютно точно.
