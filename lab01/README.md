## Исходные данные:

- **Название заказа:** Сувенирная мастерская
- **Имя заказчика:** Иван
- **Позиция 1:** Значки
  - Количество: 15
  - Цена: 120.00 руб.
- **Позиция 2:** Брелоки
  - Количество: 8
  - Цена: 250.00 руб.
- **Стоимость доставки:** 300.00 руб.
- **Внесённая сумма:** 4500.00 руб.

## Ручной расчёт ожидаемых значений:

1. **Стоимость Позиции 1:** 15 * 120.00 = 1800.00 руб.
2. **Стоимость Позиции 2:** 8 * 250.00 = 2000.00 руб.
3. **Стоимость товаров без доставки:** 1800.00 + 2000.00 = 3800.00 руб.
4. **Общая сумма с доставкой:** 3800.00 + 300.00 = 4100.00 руб.
5. **Общее количество единиц:** 15 + 8 = 23 шт.
6. **Сдача:** 4500.00 - 4100.00 = 400.00 руб.
